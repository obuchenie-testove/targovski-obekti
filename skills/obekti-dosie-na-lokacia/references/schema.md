# Данни за AI анализ — схема `targovski-obekti/analysis@1`

Файлът се изтегля от системата: **Експорт → „Данни за AI анализ (JSON)“**. Съдържа една зона, без настройки и ключове.

| Поле | Какво съдържа |
|---|---|
| `zone` | `id`, `name`, `bbox` [юг, запад, север, изток], `collected` (кога е събрана) |
| `sources` | кои източници са използвани: OpenStreetMap, `overture` (издание, добавени/съвпаднали), `chains` (вериги), `ntr` (Национален туристически регистър: записи, общо легла), `nsi` (курорт и адреси на таблиците) |
| `groups`, `categories` | 7 общи категории и 25 бранша; `typical_m2` е типичната площ на бранша |
| `shops[]` | обект: `name`, `brand`, `cat`, `group`, `lat`, `lon`, `area_m2`, `area_method` (измерена / по сграда / типична / потвърдена / от източника / от сайта), `area_err` (0.35 = ±35%), `area_confirmed` (реална площ, ако е въведена), `mall`, `address`, `phone`, `website`, `hours`, `sources`, `flow_per_day` (модел на пешеходния поток покрай обекта, ако е изчислен), `popular_hours` (натовареност по часове от веригата, скала 0–10) |
| `stays[]` | място за настаняване: `name`, `beds`, `beds_source` (НТР = официален регистър; „от OSM“, „стаи × 2“, „по сграда“, „типично“ = оценки), `stars`, `lat`, `lon` |
| `malls[]` | търговски центрове: име, място, застроена площ |
| `other_shops_count` | магазини извън 25-те бранша |
| `coverage` | контролни проби на терен (`samples`: на картата / реално) и `rate` — дял на познатите обекти |
| `calibration` | по метод на площта: брой потвърждения, медианна грешка, систематично отклонение |
| `nsi` | данни на НСИ за курорта: `annual` и `monthly`/`quarterly` (пренощували, нощувки, легла, места, легладенонощия, приходи), `summary` (година, заетост, среден престой, пиков месец) |
| `guests_by_month` | гости на нощ по месеци 1–12 и източник |
| `bed_base` | всички легла в курорта, спрямо които се смята заетостта |
| `opportunities_by_group` | до 3 места за всяка обща категория с много легла и малко обекти наоколо: `beds_400m`, `shops_400m`, най-близкият обект и разстояние |
| `flows` | дали в експорта има потоци и за кой месец и част от деня |
| `notes` | ограниченията на данните |

## Какво е факт и какво е оценка

- **Факт (с източник):** име, място и бранш на обекта според източника; легла с `beds_source = "НТР"`; данните на НСИ; натовареност по часове от веригата; потвърдени площи.
- **Оценка (с грешка):** площи без `area_confirmed`; легла с друг източник; гости по месеци, разпределени по хотели.
- **Модел (за сравнение, не за броене):** `flow_per_day`, `opportunities_by_group`.
- **Непълнота:** броят обекти е колкото познават източниците. Без контролни проби (`coverage.rate = null`) се пише „поне N“.
